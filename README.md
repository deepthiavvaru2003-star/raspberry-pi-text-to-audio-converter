# 🧠 Raspberry Pi Text-to-Audio Converter for Visually Impaired
### AI-Optimized OCR + TTS System (Accuracy: 45% → 85%)

> An assistive IoT device that converts printed text to audio in real-time to help visually impaired people read independently.

### 🚀 Key Achievement - AI Optimization
This project was **optimized using ChatGPT, Claude, and Gemini**:
- **Before AI:** 45% accuracy, slow response
- **After AI:** 85%+ accuracy, 40% faster processing
- Techniques: Adaptive thresholding, Image preprocessing, Error handling

### 🛠️ Hardware Used
- Raspberry Pi 4
- Pi Camera Module / USB Camera
- Button, Speaker, Power Supply

### 💻 Software Stack
- Python 3.9+
- OpenCV (Image Processing)
- Tesseract OCR (Text Recognition)
- gTTS (Text-to-Speech)

pip install -r requirements.txt
